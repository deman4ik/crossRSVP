# CrossRSVP

CrossRSVP — прошивка для Xteink X3, X4 и X4 Pro на основе [CrossPoint Reader](https://github.com/crosspoint-reader/crosspoint-reader). Она сохраняет обычное постраничное чтение и добавляет **RSVP**: слова из книги появляются по очереди в одной строке, так что взгляд не нужно переносить по странице.

Исходная база форка — **CrossPoint Reader 1.6.0** из ветки `develop`, [коммит `46d9125`](https://github.com/crosspoint-reader/crosspoint-reader/commit/46d912535f57e3b9ba5924717792ed1a92166c57). Номер версии CrossRSVP ведётся отдельно; текущий выпуск — **v0.9.0**.

[Сайт и пример RSVP](https://deman4ik.github.io/crossRSVP/) · [Скачать прошивку](https://github.com/deman4ik/crossRSVP/releases/tag/v0.9.0) · [Подробное руководство по RSVP](docs/rsvp.md)

## Что добавляет CrossRSVP

- **Чтение слово за словом.** В EPUB можно переключиться из постраничного режима в RSVP. Опорная буква остаётся на одном месте и выделяется жирным начертанием; обновляется широкая строка со словом.
- **Управление темпом.** Можно менять число слов в минуту, ставить чтение на паузу, переходить к следующему слову или возвращаться назад. Реальная скорость зависит от обновления E-Ink; слова не пропускаются ради заданного темпа.
- **Группировка коротких слов.** По желанию рядом с основным словом показываются до двух коротких служебных слов. Язык группировки выбирается для каждой книги: автоматически по языку EPUB, русский или английский.
- **Общая позиция чтения.** При возврате из RSVP книга открывается там, где вы остановились. Если встречается изображение, таблица или другое содержимое, которое нельзя показать в RSVP, можно вернуться к странице или пропустить объект.
- **Управление на разных устройствах.** На X3 и X4 используются кнопки; на X4 Pro доступна также сенсорная панель управления RSVP.

Книги по-прежнему открываются в постраничном режиме. RSVP включается вручную из меню чтения и начинает работу на паузе. Подробности о кнопках, сенсоре и настройках — в [руководстве по RSVP](docs/rsvp.md).

## Установка

Если пока установлена заводская прошивка, сначала следуйте [официальной инструкции по установке CrossPoint](https://github.com/crosspoint-reader/crosspoint-reader#install-firmware). Если запись прошивки по USB заблокирована, у CrossPoint есть [отдельная инструкция](https://crosspointreader.com/unlock). **CrossRSVP не входит в список прошивок, официально поддерживаемых CrossPoint Unlocker:** не загружайте файл CrossRSVP в этот инструмент. Ознакомьтесь с предупреждениями CrossPoint перед установкой другой прошивки на заблокированное устройство.

Если на устройстве уже стоит CrossPoint Reader или CrossRSVP:

1. Сохраните копию книг и настроек с SD-карты. Скачайте `.bin` **для своей модели** из таблицы выше и сравните SHA-256 с файлом [`SHA256SUMS`](https://github.com/deman4ik/crossRSVP/releases/download/v0.9.0/SHA256SUMS) из того же выпуска.
2. Скопируйте `.bin` на SD-карту. Если используете режим передачи файлов по USB на X4 Pro, безопасно извлеките накопитель на компьютере, затем выйдите из режима USB Transfer на ридере и дождитесь его перезапуска.
3. На ридере откройте **Настройки → Система → Обновление системы с SD-карты** (*Settings → System → SD Card Firmware Update*). Выберите файл, подтвердите обновление и дождитесь перезапуска. Не выключайте устройство во время установки.
4. Откройте EPUB и выберите в меню книги **Режим чтения RSVP**. В панели инструментов этот пункт находится в **«Прочее» / More**.

Пошаговая установка, проверка файла и возврат к прежней версии описаны в [подробной инструкции](docs/rsvp-release-installation.md).

## Возможности базового CrossPoint

CrossRSVP сохраняет библиотеку, постраничное чтение, настройки и другие функции базовой прошивки. О чтении EPUB и других форматов, шрифтах, словаре, закладках и управлении устройством читайте в [руководстве CrossPoint](https://github.com/crosspoint-reader/crosspoint-reader/blob/46d912535f57e3b9ba5924717792ed1a92166c57/USER_GUIDE.md). Обзор передачи книг по Wi-Fi, OPDS, синхронизации KOReader и остальных возможностей есть в [README исходной версии](https://github.com/crosspoint-reader/crosspoint-reader/blob/46d912535f57e3b9ba5924717792ed1a92166c57/README.md).
