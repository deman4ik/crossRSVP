# Установка и откат crossRSVP X3 v0.2

Инструкция относится только к экспериментальной сборке **Xteink X3 / EPUB**. Автоматические host-тесты и X3
симулятор пройдены, но длительная проверка на физическом X3 ещё обязательна. Не устанавливайте эту сборку на X4,
X4 Pro, X4C, Sticky или другое устройство.

## Сборка

Узнайте Python, которым реально пользуется PlatformIO, и один раз установите зависимости именно в него:

```bash
pio system info
uv pip install --python "<Python Executable из вывода выше>" -r requirements-platformio.txt
```

Соберите финальный образ:

```bash
pio run -e rsvp_x3_release -j 1
```

Результат и контрольная сумма появятся здесь:

- `artifacts/rsvp-x3-v0.2/firmware/crossrsvp-x3-v0.2-experimental.bin`
- `artifacts/rsvp-x3-v0.2/firmware/SHA256SUMS`

Перед установкой выполните `shasum -a 256` для `.bin` и сравните результат с `SHA256SUMS`.

## Резервная копия

1. Зарядите X3 и оставьте его на стабильном USB-питании.
2. Выключите устройство, извлеките SD-карту и скопируйте её целиком, включая скрытый каталог `/.crosspoint`.
3. Сохраните установленный сейчас известный рабочий `.bin`: он нужен для обычного отката.
4. Если X3 разблокирован для USB-прошивки, дополнительно сохраните полный образ 16 MiB:

```bash
pio pkg exec -p tool-esptoolpy -- esptool.py \
  --chip esp32c3 -p /dev/cu.usbmodemXXXX -b 921600 \
  read_flash 0x000000 0x1000000 x3-flash-backup.bin
shasum -a 256 x3-flash-backup.bin
```

## Установка с SD-карты

1. Скопируйте `crossrsvp-x3-v0.2-experimental.bin` на SD-карту.
2. Откройте **Настройки → Система → Обновление прошивки с SD-карты**.
3. Выберите файл, подтвердите обновление и не отключайте питание до перезапуска.
4. Проверьте, что устройство сообщает версию `0.2.0-crossrsvp-experimental-x3`.

Для уже разблокированного USB-устройства также можно использовать **Custom .bin** в
[веб-установщике CrossPoint](https://crosspointreader.com/#flash-tools), обязательно выбрав X3.

## Быстрая проверка

1. Откройте EPUB: книга должна сначала появиться в Paged Mode.
2. Войдите в RSVP и убедитесь, что первое слово показано на паузе.
3. На скорости 240 WPM нажмите Pause и Back во время refresh: команды должны выполниться сразу после текущего
   физического обновления.
4. Вернитесь из RSVP в Paged и обратно без навигации: должно повториться последнее фактически показанное слово.
5. Перезапустите устройство и повторите вход в RSVP; позиция должна сохраниться.
6. Выполните явный переход страницы или главы: старое RSVP-слово не должно восстановиться.
7. Очистите производный кэш книги: прогресс и RSVP checkpoint должны сохраниться.

Полная карта управления находится в [русской инструкции RSVP](rsvp-controls-ru.md), а состояние автоматической и
физической квалификации — в [отчёте v0.2](qualification/rsvp-x3-v0.2/README.md).

## Откат

Если основной интерфейс работает, установите сохранённый рабочий X3 `.bin` тем же способом через SD-карту. Если
интерфейс не запускается, положите известный рабочий X3 `.bin` на SD, выключите устройство, удерживайте левую боковую
кнопку при нажатии Power и выберите файл в recovery picker. Для разблокированного устройства можно применить Custom
`.bin` веб-установщика. Не придумывайте команду полной записи сохранённого 16 MiB образа: при тяжёлом сбое следуйте
[инструкции восстановления](fix-bricked-xteink.md).
