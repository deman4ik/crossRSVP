# CrossRSVP v0.5.0 — X3, X4 и X4 Pro

Подготовлен к просмотру перед публикацией. GitHub Release, тег и push ожидают
отдельного подтверждения. После публикации до физических испытаний использовать
отметку pre-release; слово `experimental` в названии отсутствует.

## Изменения

- Отдельные образы CrossRSVP для X3, оригинального X4 и X4 Pro с общей версией 0.5.0.
- X4 Pro: сенсорный вход и полная панель управления RSVP — запуск, шаг,
  перемотка на пять групп, темп, настройки и Paged Mode.
- Пауза касанием области чтения; панель появляется без смещения ORP.
  Отпускание касания не запускает чтение повторно.
- Освещение и настройки сохраняют паузу и текущую группу. Возврат из настроек
  применяет изменения к той же сессии.
- Кнопочное управление X3/X4 сохранено. Pro использует профиль ESP32-S3 с PSRAM,
  USB MSC и SDMMC; C3 не требует PSRAM.

## Результаты

Host-тесты: **299/299**. Симуляторы: **54 сценария** — X3 15, X4 15, X4 Pro 24
(13 основных, 8 для шрифтов 12/18 pt, 2 для непомещающегося слова и вход через More). Проверены четыре ориентации, позиции после
возврата/сна, границы содержимого, ошибки, задержанный refresh и сенсорные действия.

| Модель | Профиль | Статический RAM, байт | Flash приложения, байт |
| --- | --- | ---: | ---: |
| X3 | `rsvp_x3_release` | 56 260 | 5 425 985 |
| X4 | `rsvp_x4_release` | 56 260 | 5 425 985 |
| X4 Pro | `rsvp_x4pro_release` | 89 684 | 5 340 158 |

Статический RAM из отчёта линковщика не равен доступному heap во время чтения.
Все три образа укладываются в раздел приложения 6 553 600 байт.
