# CrossRSVP v0.9.0 — выпуск для X3, X4 и X4 Pro

Выберите файл, соответствующий модели вашего ридера. Все три образа сохраняют
обычное постраничное чтение и режим RSVP: слова из книги последовательно
появляются в широкой строке вокруг неподвижной опорной буквы.

| Модель | Файл | Обновление широкой строки RSVP |
| --- | --- | --- |
| Xteink X3 | `crossrsvp-x3-v0.9.0.bin` | Прежняя передача полного буфера в контроллер; проверена на одном X3 |
| Xteink X4 | `crossrsvp-x4-v0.9.0.bin` | Прежняя передача полного буфера; вариант из предыдущего пользовательского выпуска |
| Xteink X4 Pro | `crossrsvp-x4pro-v0.9.0.bin` | 20 МГц SPI и передача только области строки в RAM UC8279; проверена на одном X4 Pro |

X3 и X4 не получают экспериментальную короткую запись в RAM контроллера.
Несколько диагностических вариантов этой записи на X3 завершались ошибкой
экрана, несмотря на чистое слово и восстановленную страницу. Они не входят в
этот выпуск. X4 Pro получает последний вариант, для которого пользователь
подтвердил чистые слова и страницу после выхода из RSVP. Узкая область одного
слова отключена из-за заметных следов предыдущих символов: на всех моделях
остаётся широкая строка.

В измерении на одном X3 прежняя широкая строка дала 130 кадров за 60,056 с,
или 129,88 кадра/мин. На одном X4 Pro ускоренная широкая строка дала
122 кадра/мин и среднее время обновления 469 мс за два запуска более 60 с;
было 120 частичных обновлений и один начальный полный кадр без ошибок и
откатов. Это результаты конкретных устройств, а не обещанная скорость для
каждой книги и панели. Физических замеров на X4 пока нет.

Файлы `.bin`, `SHA256SUMS`, `firmware-manifest.json`, `INSTALL.md` и
`VALIDATION.md` приложены к [релизу v0.9.0](https://github.com/deman4ik/crossRSVP/releases/tag/v0.9.0).
Сверьте SHA-256 перед установкой. Подробные шаги и откат описаны в
[инструкции](rsvp-release-installation.md), а границы проверки — в
[отчёте о валидации](rsvp-v0.9.0-validation.md). Диагностические образы и результаты
сохранены отдельно; их не следует устанавливать вместо файлов этого релиза.
