# Установка и откат crossRSVP X3 v0.4.0

Инструкция относится к экспериментальному кандидату **Xteink X3 / EPUB**. Версия v0.4.0 не имеет физической
квалификации устройства; перед установкой сохраните рабочую прошивку и полную копию SD-карты. Не устанавливайте
кандидат на X4, X4 Pro, X4C, Sticky или другое устройство.

## Сборка

Узнайте Python, которым реально пользуется PlatformIO, и один раз установите зависимости именно в него:

```bash
pio system info
uv pip install --python "<Python Executable из вывода выше>" -r requirements-platformio.txt
```

Соберите образ кандидата:

```bash
pio run -e rsvp_x3_release -j 1
```

Ожидаемые артефакты:

- `artifacts/rsvp-x3-v0.4.0/firmware/crossrsvp-x3-v0.4.0-experimental.bin`
- `artifacts/rsvp-x3-v0.4.0/firmware/SHA256SUMS`

Перед установкой выполните `shasum -a 256` для `.bin` и сравните результат с `SHA256SUMS`.

## Резервная копия

1. Зарядите X3 и оставьте его на стабильном USB-питании.
2. Выключите устройство, извлеките SD-карту и скопируйте её целиком, включая скрытый каталог `/.crosspoint`.
3. Сохраните установленный сейчас известный рабочий `.bin`: он нужен для отката.
4. Если X3 разблокирован для USB-прошивки, дополнительно сохраните полный образ 16 MiB:

```bash
pio pkg exec -p tool-esptoolpy -- esptool.py \
  --chip esp32c3 -p /dev/cu.usbmodemXXXX -b 921600 \
  read_flash 0x000000 0x1000000 x3-flash-backup.bin
shasum -a 256 x3-flash-backup.bin
```

## Установка с SD-карты

1. Скопируйте `crossrsvp-x3-v0.4.0-experimental.bin` на SD-карту.
2. Откройте **Настройки → Система → Обновление прошивки с SD-карты**.
3. Выберите файл, подтвердите обновление и не отключайте питание до перезапуска.
4. Проверьте, что устройство сообщает версию `0.4.0-crossrsvp-experimental-x3`.

Для уже разблокированного USB-устройства также можно использовать **Custom .bin** в
[веб-установщике CrossPoint](https://crosspointreader.com/#flash-tools), обязательно выбрав X3.

## Быстрая проверка

1. Откройте EPUB: книга должна сначала появиться в Paged Mode.
2. Включите **Настройки → Чтение → Группировка коротких слов** и войдите в RSVP.
3. Проверьте фразы `я не сделал бы`, `а он пришёл` и `это сделал я`: Active Word остаётся единственным словом с ORP,
   а компаньоны отображаются целиком и в исходном порядке.
4. Проверьте запятые, тире, конец предложения, абзац, главу, изображение и таблицу: группа не должна пересекать
   границу, а не поместившееся слово-компаньон должно появиться отдельно.
5. Проверьте пуск/паузу, изменение скорости, перемотку на пять Presentation Groups и одиночный шаг.
6. Вернитесь из RSVP в Paged: последняя физически подтверждённая Presentation Group должна определять позицию.
7. Перезапустите устройство и снова откройте книгу: сохранённая группа не должна повторять компаньона отдельно.
8. Проверьте обе строки Focus Reading — в **Настройки → Чтение** и во вложенном **Настройки текста → Стиль**.

Полная карта управления находится в [русской инструкции RSVP](rsvp-controls-ru.md), а статус кандидата — в
[отчёте v0.4.0](qualification/rsvp-x3-v0.4.0/README.md).

## Откат

Если основной интерфейс работает, установите сохранённый рабочий X3 `.bin` тем же способом через SD-карту. Если
интерфейс не запускается, положите известный рабочий X3 `.bin` на SD, выключите устройство, удерживайте левую
боковую кнопку при нажатии Power и выберите файл в recovery picker. Для разблокированного устройства можно применить
Custom `.bin` веб-установщика. Не используйте сохранённый 16 MiB образ как обычный OTA-файл: при тяжёлом сбое
следуйте [инструкции восстановления](fix-bricked-xteink.md).
